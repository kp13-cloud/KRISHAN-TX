🚀 About

KRISHAN-TX is a customized terminal toolkit created for security learning and authorized testing environments.

The project provides a simple command-line interface for working with security-learning utilities and local test environments.

«⚠️ Use only on systems, applications, and networks that you own or have explicit permission to test.»

---

✨ Features

- 🎨 Colorful terminal interface
- ⚡ KRISHAN-TX FIGlet banner
- 🛠️ Security-learning utilities
- 🌐 Local testing environment
- 📁 Organized project structure
- 📱 Termux/Android friendly
- 🔧 Customizable Bash-based interface

---

📱 Installation

Termux

Install the required packages:

pkg update
pkg install git bash figlet -y

Clone the repository:

git clone https://github.com/kp13-cloud/KRISHAN-TX.git

Enter the directory:

cd KRISHAN-TX

Make the launcher executable:

chmod +x scripts/launch.sh

Start the toolkit:

bash scripts/launch.sh

---

🖥️ Usage

Launch KRISHAN-TX from the project directory:

cd ~/KRISHAN-TX
bash scripts/launch.sh

The launcher displays the KRISHAN-TX interface and starts the project's authorized security-learning components.
